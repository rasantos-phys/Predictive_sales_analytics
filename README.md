## 🎯Objective
To develop a machine learning model to predict future sales based on historical data, supporting strategic business decisions.

## 🛠️ Stack
- **Python 3.9+**
- **Pandas** - Data manipulation
- **NumPy** - Numerical calculations
- **Matplotlib & Seaborn** - Data visualization
- **Scikit-learn** - Machine learning modeling

## 📁 Project Structure
├── PROJECT01_Predictive_Sales_Analysis_with_Linear_Regression.ipynb # Main notebook containing the full analysis
├── vendas.csv # Dataset used
├── README.md # This file
└── LICENSE # MIT License

## 📈 Results
- Linear regression model with **R² = 0.99**
- High predictive capability for sales planning
- Identification of a consistent growth trend

## 💡 Business Conclusions
1. The model is reliable for short- and medium-term forecasts
2. There is a sustainable linear growth trend
3. The time variable is a strong predictor of sales
